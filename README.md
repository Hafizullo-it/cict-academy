# CICT Academy — сайт, который строят ИИ-агенты

Лендинг образовательного центра **CICT Academy** (Instagram [@cict_academy](https://www.instagram.com/cict_academy/)).

При открытии страница начинается с пустого белого листа: 9 ИИ-агентов (Theme, Logo, Copy, Writer, Editor, UI, Design, Layout, Code)
красят фон, рисуют логотип, собирают блоки и печатают тексты. При прокрутке они достраивают каждый следующий раздел.

- Один файл `index.html`, без сборки и зависимостей.
- `?fast` в адресе — открыть сайт сразу собранным.
- Учитывается `prefers-reduced-motion`.
